# Access Architecture

Official website for the emerging field of Access Architecture.

## Definition

Access Architecture is the study and design of conditions that influence access to preserved abilities.

## Website

https://accessarchitecture.github.io

## Status

This repository currently hosts the public landing page for the field. Additional papers, frameworks, and documentation will be added as the field develops.
